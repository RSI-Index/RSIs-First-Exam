# Reference path

The reference solution runs the unchanged editable starter through the real attempt lifecycle. It therefore exercises the same frozen 1,000-round Slime Search-R1 command, CPU BM25 service, checkpoint save/export, selection, provenance, and control-completion paths as a research submission.

This is a baseline receipt, not a claim that GRPO is optimal. A participant should change one interpretable allowlisted mechanism in `rl_research/algorithm_config.toml`, state the expected hidden exact-match effect, and compare the completed attempt with this starter.

The task has not yet completed its required Docker, minimal multi-GPU, full 1,000-round 8xH100 baseline, or end-to-end verifier release gates. Those remain explicitly `UNVERIFIED` in `VALIDATION.md`; the reference script is not evidence that those expensive paths have run.
